# Game compatibility

> <sub>This document was generated by Anthropic's Claude Fable 5.2.</sub>

This is a skill package for Miyu. It provides one skill, `game-compat`, which checks whether a game can be played on Linux (including the Steam Deck) and on a Mac with Apple Silicon. When you ask "Does this game run on a Mac?" or "Will it run on Linux?", the AI uses this skill to look it up and returns the results from several sources side by side.

| Platform | Source | What it gives |
|---|---|---|
| Linux | ProtonDB | The ratings (overall, recent, best), the number of reports, and the latest few player reports: the verdict, the Proton version, the problems hit, the launch options, notes |
| Linux | AreWeAntiCheatYet | The anti-cheat status (`Supported`, `Denied` and so on), which anti-cheat is used, the latest changes |
| Linux | caniplayonlinux | A one-sentence verdict and the date it was last verified |
| Steam Deck | Steam (Valve's testing) | `已验证` (Verified), `可游玩` (Playable), `不支持` (Unsupported), and the reasons Valve gives |
| Mac | MacGamingDB | The rating, the number of reports, how players run the game (native, CrossOver, Parallels), and the latest few reports: the chip, the translation layer, the frame rate, the graphics settings, notes |

The AI runs the skill's script in `shell`, and you can also run it yourself, for example:

```sh
python3 skills/game-compat/scripts/game_compat.py "Elden Ring" --platform mac
```

| Parameter | Description |
|---|---|
| Game | A Steam App ID or a game name, required. The original English title gives the most accurate results; a Chinese name has to match the game's Chinese Steam store name |
| `--platform` | `linux`, `mac`, `all`, default `all` |
| `--chip` | Only show reports for one Mac chip, for example `M1` or `M2 Pro`; `M1` includes the Pro, Max and Ultra |
| `--reports` | The number of player reports listed for each source, 0–20, default 6; 0 gives only the ratings |
| `--json` | Output JSON for use by code |

- The script first identifies the game and then looks it up: an App ID is turned into a name through Steam; an English name is identified through ProtonDB's search index; for a Chinese name, the script first looks for a game whose Chinese Steam store name matches exactly and then checks what the search index returns, and an English result only counts if it matches that game's Chinese store name. If nothing matches, the script does not force a lookup; it returns what it found and asks you to use the original English title instead.
- A game that is not on Steam has no ProtonDB data, but the anti-cheat status, caniplayonlinux and MacGamingDB can still be looked up by name. Such a game is sometimes identified as a different Steam game whose title contains its name; the first line of the output says which game it was identified as, and the skill tells the AI to check that first.
- If a source has no entry for the game, the result says `没收录` (not listed); if the lookup fails, it says `出错` (error); the two are never mixed up: not being listed does not mean there is no anti-cheat.
- The AreWeAntiCheatYet master list and the caniplayonlinux sitemap are cached for a day in `MIYU_CACHE_DIR`; when that folder is not available, they are kept in `~/.cache/miyu-game-compat`.
- The script uses only the Python standard library.

Because this package provides a skill, it does not take up space in the tool descriptions; the AI reads it only when it is needed. The MacGamingDB data comes from its public API (the project [neo773/macgamingdb](https://github.com/neo773/macgamingdb), MIT license).
